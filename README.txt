Paint Life website
==================
index.html  - the complete website (one file, logo is built in)
logo.jpg    - the logo (small copy, for reference)

To view: double-click index.html (needs internet for fonts only).
To put it online: upload index.html to any web hosting
(for example cPanel public_html, Netlify Drop, GitHub Pages).

To change prices or text: open index.html in a text editor
(Notepad, VS Code) and edit the list starting with "var S=[".
To add project photos: see the line starting with "var PH=" and
add src:"photo-file-name.jpg" to each item, then put the photos
in the same folder as index.html.
